آراء العملاء + عدد الزوار — تفعيل المشاركة العامة

الموقع الآن مجهز ليستخدم Supabase واحد مشترك للاثنين: آراء العملاء وعدد الزوار.

1) افتح Supabase وأنشئ مشروعًا.
2) افتح SQL Editor والصق محتوى SUPABASE_REVIEWS_SETUP.sql ثم Run.
3) من إعدادات Data API تأكد أن جدول reviews مكشوف للـData API.
4) انسخ Project URL وPublishable/Anon Key إلى site-config.js.
5) نفس الإعداد سيُستخدم للآراء وعدد الزوار.
6) ارفع الملفات مرة أخرى.

بعدها:
- أي تقييم جديد يدخل قاعدة البيانات المشتركة ويظهر لكل زوار الموقع.
- عدد الزوار/الأجهزة الفريدة يظهر بنفس الرقم للجميع.
- لا يوجد اعتماد على localStorage لعرض الآراء أو عداد محلي منفصل.

مهم: لا تضع service_role key داخل الموقع. استخدم Publishable/Anon key فقط مع سياسات RLS الموجودة في ملف SQL.
